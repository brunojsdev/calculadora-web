# 🧮 Calculadora Web

Um projeto de calculadora simples e funcional desenvolvido com HTML, CSS e JavaScript puro. A interface segue um design moderno com paleta de cores escura e detalhes em verde neon.

## 🚀 Funcionalidades

* **Operações Básicas:** Soma, subtração, multiplicação e divisão.
* **Interface Limpa:** Display que imita uma tela LCD com suporte a números grandes.
* **Responsividade:** Layout adaptável e botões fáceis de clicar.
* **Tratamento de Erros:** Exibe mensagem de erro caso a operação matemática seja inválida.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estrutura semântica.
* **CSS3:** Estilização com variáveis CSS (`var(--cor...)`), Flexbox e Grid Layout.
* **JavaScript (Vanilla):** Lógica de cálculo utilizando manipulação de strings e `eval()`.

## 📦 Como usar

1. Faça o clone deste repositório ou baixe o arquivo `calculadora.html`.
2. Abra o arquivo `calculadora.html` em qualquer navegador moderno (Chrome, Firefox, Edge).
3. Utilize o mouse para clicar nos botões e realizar os cálculos.
